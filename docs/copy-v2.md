# joinfediverse.kr 카피 v2 — 다듬은 초안

## 작업 원칙

1. **이념 어휘 회피**: "탈중앙·프로토콜·연합우주·페디버스·서버·인스턴스·소유권·데이터 주권"은 첫 화면에서 한 글자도 안 씀.
2. **두 마리 토끼**: 진입장벽 낮추기 + "플랫폼을 넘는 연결" 둘 다 잡되, *말이 아니라 그림*으로 (핸들 도메인이 다 다른 것, 여러 앱 로고가 한 화면에 같이 뜨는 것).
3. **소유권 프레임 제거**: "내 글은 내 거"는 추상적. 대신 *구체적 안도감*("이사 가도 친구 목록 그대로").
4. **HowItWorks·시작 안내는 뒤로**: 둘러보고 마음 들면 시작 안내를 봄.
5. **부드러운 *일상* 어조**: "~해요/~예요" + 분석 대시보드 말투("총/활성/월간") 회피.
6. **알고리즘은 "부재"가 아니라 "주도권"**: FASP 로드맵 고려, "없어요" 대신 "내가 정해요".

통합 은유: **"동네"**.

## 2. Niches (`#live`)

- **이브로우**: `지금 이 순간` *(유지)*
- **섹션 헤드**: `요즘 사람들 / **이런 글** 쓰고 있어요.`
- **서브**: `**기본은** 시간 순서대로 흘러요. 팔로우한 사람의 글이 그대로.`
- **익스플레인 3개** (FASP 반영 — 옵션 C):
  - **01 피드는 내가 정해요**
    `기본은 시간 순서대로 — 알고리즘에 끌려다니지 않아요. 필요하면 추천을 켜고, 마음에 안 드는 글은 살짝 가려요. 내가 키를 잡는 피드.`
  - **02 다른 동네 사람도 보여요**
    `같은 망에 있어서 답장·팔로우가 동네 경계를 넘어요.`
  - **03 광고 없어요**
    `대부분의 동네는 후원으로 운영돼요. 피드는 내 취향 그대로.`

## 5. HowItWorks (`#how`)

- **이브로우**: `원리` *(유지)*
- **섹션 헤드**: `작은 동네들이 / **서로 이어져** 있어요.`
- **서브**: `동네마다 운영자도 규칙도 분위기도 달라요. 하지만 **같은 망에 있어서**, 한 동네 계정으로 다른 동네 사람들을 팔로우하고 답장할 수 있어요.`
- **포인트 3개**:
  - **01 한 곳에 가입하면 충분** — `한 계정으로 다른 동네, 다른 앱(Pixelfed·PeerTube 등)의 사람들과 교류할 수 있어요.`
  - **02 동네는 작은 공동체** — `관심사나 언어, 분위기가 맞는 곳을 고르면 돼요. 마음에 안 들면 옮기면 됩니다.`
  - **03 옮겨도 관계가 남아요** — `동네 이사 기능이 기본. 팔로우 관계가 함께 따라옵니다.`
- **다이어그램 내부**:
  - srv 라벨: `800 사용자` → `800명` (전부 동일 패턴)
  - 중심 라벨 `ActivityPub / 공통 프로토콜` → `같은 망 / 동네들이 이어진 곳`

## 6. Possibilities (`#start`)

- **이브로우**: `시작하기` *(유지)*
- **섹션 헤드**: `세 단계면 / **충분해요**.` *(유지)*
- **서브**: `처음부터 완벽한 동네 안 골라도 돼요. 마음에 안 들면 이사 갈 수 있어요. 친구 목록도 그대로요.`
- **단계 3개**:
  - **01 동네 고르기** — `위 동네 중 분위기가 맞는 곳을 하나 고르세요. "여기 사람들과 이야기하고 싶은가"가 기준이에요.`
  - **02 가입하기** — `이메일과 사용자명만 있으면 시작할 수 있어요. **한 곳 가입으로 모든 동네와 이어져요.**`
  - **03 팔로우하기** — `관심 있는 해시태그와 사람부터 팔로우. 짧은 자기 소개 글이 가벼운 첫 게시물로 좋아요.` *(유지)*
